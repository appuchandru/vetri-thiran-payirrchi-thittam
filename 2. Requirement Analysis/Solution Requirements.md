## Functional Requirements

| FR No. | Functional Requirement | Description | Priority |
| --- | --- | --- | --- |
| FR-1 | User Registration and Login | Users register with email and password and log in securely | High |
| FR-2 | Budget Setup | User sets monthly budget and category limits | High |
| FR-3 | Expense Management | Add, edit, delete and view expenses with category and date | High |
| FR-4 | Expense Categorisation | Automatically suggest a category from the expense description | Medium |
| FR-5 | Budget Alerts | Notify the user at 80% and 100% of budget usage | High |
| FR-6 | Recommendation Engine | Suggest courses, books and tools that fit the user's budget and interests | High |
| FR-7 | Gen AI Chat Assistant | Answer budget and saving questions in natural language | High |
| FR-8 | Dashboard and Reports | Show spending charts, category split and monthly summary | High |
| FR-9 | Savings Goal Planner | Set a goal and track progress with saving tips | Medium |

## Non-Functional Requirements

| NFR No. | Requirement | Description |
| --- | --- | --- |
| NFR-1 | Usability | Simple interface that a first-time student can use without training |
| NFR-2 | Performance | Pages load in under 3 seconds and chat replies in under 8 seconds |
| NFR-3 | Security | Passwords hashed, API keys kept in environment variables |
| NFR-4 | Reliability | System shows friendly messages if the AI service is unavailable |
| NFR-5 | Scalability | Modular design so more recommendation sources can be added |
| NFR-6 | Privacy | User financial data is visible only to that user |
