| S.No. | Section | Details |

| 1 | Introduction | EduGenie is a Gen AI powered assistant that helps students track their budget and receive affordable, personalised recommendations |
| 2 | Purpose | Improve student financial awareness and reduce overspending while making learning resources affordable |
| 3 | Scope | Expense tracking, budget alerts, recommendations, AI chat, dashboard and savings goals for students |
| 4 | Problem Statement | Students lack one tool that combines budget tracking with budget-aware recommendations |
| 5 | Target Users | College students aged 17 to 24 |
| 6 | Proposed Solution | Streamlit web app with a Python backend, SQLite database and Gemini API for conversational guidance |
| 7 | Key Features | Login, budget setup, expense management, auto-categorisation, alerts, recommendations, AI chat, dashboard, savings planner |
| 8 | Technology Stack | Streamlit, Python, Gemini API, scikit-learn, pandas, SQLite, Plotly, pytest |
| 9 | System Architecture | Three layers: Presentation (Streamlit), Application (Python services) and Data (SQLite) with external Gemini API |
| 10 | Database Design | Tables: users, budgets, expenses, resources, goals, chat_history |
| 11 | Testing Summary | 12 functional and 6 performance test cases defined in Phase 6 |
| 12 | Limitations | Depends on internet for AI features, recommendation dataset is limited to sample data, no bank integration |
| 13 | Future Enhancements | Bank and UPI integration, mobile app, regional language support, voice assistant, live price fetching |
| 14 | Conclusion | EduGenie gives students an easy, intelligent way to manage money and choose affordable resources |
